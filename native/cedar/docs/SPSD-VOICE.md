# Real SPSD AICA to native float producer

`SpsdVoice` connects the actual `SpsdAicaStream` resource decoder to an **unbound** SDL audio conversion stream. It neither opens an audio device nor initializes SDL, plays, mixes, schedules dialogue or associates a resource with a story event. Caller serializes all methods and keeps the original source bytes immutable/alive until stop. No rewind/loop/silence/timer is invented.

`start(view, output_channels)` requires empty state and explicit one/two output channels. The real source metadata supplies signed native-endian PCM16 rate/channel count; SDL converts to native-endian float at 48000Hz and caller-selected channels. Underlying source/codec restrictions and ISC provenance remain documented in `SPSD-AICA.md` and retained `third_party/licenses/vgmstream-yamaha-ISC.txt`. The bridge itself is original code, not copied SDL implementation.

## Bounded production and failure truth

- `pump` requests an exact nonzero source-frame count within decoder bounds, using caller PCM16 interleaved output plus mono scratch. Full declared capacities (not only written prefixes), alignment, pointer arithmetic and pairwise scratch/source/entire-voice-object disjointness are validated before any write. The decoder repeats its own precise preflight. Full source includes the caller's complete borrowed slice.
- Before decoding, actual `SDL_GetAudioStreamQueued` input bytes plus the proposed PCM16 bytes must fit 1MiB. `queue_full` changes no decoder state; read output to make room or reduce the request. Queue accounting is actual unconverted input, not a fabricated resampled-frame estimate. A single request can therefore be stricter than the decoder's frame maximum.
- On successful decode, its state is already committed before SDL copies input with `SDL_PutAudioStreamData`. A Put failure latches faulted, reports `decoder_advanced=true` and `queue_acceptance_uncertain=true`, preserves nested decoder diagnostics, and prohibits retrying that chunk. Stop/restart is explicit; no rollback or duplicate-queue retry is claimed. Decoder failure also faults the bridge and preserves exact nested output/scratch modification diagnostics.
- `read` accepts a whole number of output frames in caller float storage, up to 1MiB per call, checks the full storage span against source/object, and returns actual produced frames/bytes. Zero available data yields zero valid frames, never padding. `SDL_GetAudioStreamData` performs conversion when consumed. Negative return faults with possible output modification and uncertain converter consumption. Contract-invalid byte counts fault with output invalid. On a successful read, `converted_bytes` records actual removed output bytes even if subsequent finite validation fails.
- All returned samples are checked finite before clipping. A nonfinite sample faults and invalidates the entire returned buffer; discard it. Finite resampling overshoot is hard clipped to [-1,1] with an exact clipped-sample count. This is an explicit downstream PCM contract, not an audio-quality claim. Samples beyond the actual returned prefix remain caller-owned and untouched by the bridge.

`output_valid` refers to read float output only. Pump reports source decode validity through its nested result, and `output_modified` there describes caller PCM scratch output. On any fault the converter is not reused; `last_error` copies SDL errors for native failures. Nested decoder fields describe codec/source failures. Stop destroys only this unbound converter and decoder state, not an audio subsystem or device.

## End and drain

`finish` is legal only after source frames remaining reaches zero; it explicitly flushes exactly once, making the resampler tail available. Read until `drain_status().drained`: true requires source exhaustion, successful explicit flush and actual converted available bytes equal zero. Source exhaustion before flush or temporarily zero available data while feeding is not EOF. No more pump is permitted after flush; reads remain possible. The SDL stream handle is private, with no callbacks or external format/queue mutations allowed.

Primary API evidence is the selected read-only SDL3 `SDL_audio.h`: CreateAudioStream, PutAudioStreamData copy semantics, GetAudioStreamData conversion timing/byte count, GetAudioStreamQueued unconverted-input count, GetAudioStreamAvailable and FlushAudioStream. Path: `<LOCAL_REFERENCE>/SDL_audio.h`. An embedding app supplies SDL lifetime consistent with its platform; this facility makes no implicit audio initialization assumption or device-availability claim.

Source-only integration: no worker compilation, runtime, playback, assets or tests. Lead owns batch compilation/link; real dialogue/audio-system binding remains separate.
